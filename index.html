⚙️ API 설정

Google Custom Search API를 사용하여 이미지를 검색합니다. 무료로 하루 100회 검색 가능합니다.

📋 1회 설정 방법

  1. Google Cloud Console에서 API 키 발급
  2. Custom Search API 활성화
  3. Custom Search Engine 생성 (이미지 검색 ON)
  4. 아래에 API 키와 검색엔진 ID(cx) 입력
